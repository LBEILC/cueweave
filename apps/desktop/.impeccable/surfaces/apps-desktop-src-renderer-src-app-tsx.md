# Desktop shell

Mode: Operate. Scope: the Electron application shell, persistent media player, D1/D2 project editing, translation and export sidebar, import flow, and About overlay. Follow docs/DESKTOP.md for desktop product requirements and DESIGN.md#desktop-workspace for the user-confirmed direction.

## Direction contract

THESIS: A window-bound subtitle workspace: watching and reading stay together, and playback controls never scroll away.

OWN-WORLD: Inherit Warm Paper, neutral dark surfaces, original MiSans assets, the quote mark, and Phosphor controls. No new visual identity.

STORY: Open a file or link, watch, load subtitles, search or click a cue to locate playback. Create or open a project from the header, import a track, edit text and millisecond-precision times in the sidebar, save, undo/redo, and export original or edited SRT/WebVTT. Save and background status stay at the bottom. Collapse the subtitle panel for watching. Import and About retain the media element and return focus to their trigger. Source settings fold away once a track is loaded.

FIRST VIEWPORT: Native window frame; compact application header, current media row, video with optional right subtitle panel, fixed transport, and task status strip. The video fits remaining space. At 900px and below, the subtitle panel overlays the video area without covering playback controls. Default native window is 1280×820; normal window size is saved and clamped against the primary display work area. Minimum application window is 640×480. Empty/import/About content scrolls within its own region.

FORM: Code-led implementation of the user-confirmed A wireframe from design-from-constraints. The user explicitly approved impeccable for this implementation stage; do not reroll the visual direction. Existing Warm Paper, MiSans and Phosphor remain authoritative. The comparison is a structural reference, not a pixel-perfect image comp. No new raster assets.

QUALITY BAR: No root scroll or clipped transport at 1120×720, 960×640, and 640×480; readable long subtitles with independent scrolling; preserved media element and paused position across overlays; discoverable source controls, keyboard-safe form input, current-cue indication, light/dark parity. Project/edit/export controls include D2 translation and bilingual export; ASR has no placeholder controls. At <=900px, transport and tools occupy two rows; at <=650px content height, editing takes over the sidebar with its own scroll region. Preserve full quality labels and white-on-dark-orange primary buttons in both themes.

EVIDENCE: D1 project storage and real Electron acceptance coverage is recorded in docs/DESKTOP_D1.md. Current light/dark, narrow editor and quality-control screenshots are in .impeccable/review/desktop-project/. Deterministic MP4/WebM and a 503-cue VTT fixture in isolated Electron user data. The acceptance screenshots live in .impeccable/review/desktop-smoke/, the A/B/C comparison in .impeccable/review/desktop-redesign/. These are test fixtures, never shipped defaults. Automated media output must be muted.

FINISH: The earlier shell review is recorded in docs/desktop/2026-09-05-workspace-acceptance.md. The D1 finish review requested dark primary-button contrast and persistence fixes; its final `ship` disposition is limited to those two resolved fixes. Functional D1 evidence is maintained separately in docs/DESKTOP_D1.md. This is not a full backend or operating-system review. Built values and local video/shadow/scrim exceptions are recorded in DESIGN.md#desktop-workspace; the shared sidecar preserves extension examples and adds desktop primitives. No new shipping raster assets were introduced.

BUILT DETAILS: The viewport grid uses a 52px header and 30px status strip; media heading is at least 44px. Wide sidebar width is clamp(280px, 29vw, 380px); at <=900px it becomes a min(360px, 70%) overlay within the video region, with a local boundary shadow. At <=680px horizontal header/control padding is 12px and video inset is 8px. Dialog width is min(720px, calc(100vw - 40px)) with a 40px viewport height allowance. Controls use 8px corners, compact subtitle selects 5px, dialogs/import previews 14px. Loaded source controls collapse in a details disclosure; current cues have aria-current, a text marker, orange time, neutral selected background, and semibold text. Long lists use native scrolling and content-visibility, not a fixed-row virtualizer.

D1 BUILT DETAILS: Project tools scroll within a 40% sidebar height limit; the cue editor normally occupies up to 65%, with only fields scrolling and its heading/save fixed, with two equal time fields and a vertically resizable text area. At <=650px content height, the active editor fills remaining sidebar space while tools, source controls, search, list and footer are hidden until editing ends. Primary-button fill is --primary-fill (#b6450f) in both themes, with white text; dark --accent (#ff9859) remains the brighter text/focus emphasis. Native select arrows sit 12px from the right with 38px text padding. Project state, saved edits and recovery behavior follow docs/DESKTOP_D1.md rather than visual review claims.

D2 BUILT DETAILS: Translation parameters use a disclosure showing saved provider/model and target language. Starting folds the parameters while state, language, completed/total counts, progress, cancellation, resume and missing-cue location stay outside the disclosure. Saved translations remain under their source cues with a manual-review label and bilingual search. The editor switches between source/time and translation, blocks mode changes while dirty, hides project/source tools, and keeps save outside field scrolling. At <=650px height it takes the sidebar and hides the source reference. Export adds translation/bilingual and explicit partial output. Playback and settings share SubtitleOverlay; see DESIGN.md and docs/DESKTOP_D2.md.

D2 FINISH: Independent generic proxy visual/code review returned SHIP, with all 12 current captures in .impeccable/review/desktop-translation/ reviewed and no material findings. Expanded entry/export controls were checked through code and documentation, not screenshots. Mocked API functionality is tested separately in docs/DESKTOP_D2.md; this verdict makes no real-model translation quality or installer claim.

ONLINE BUILT DETAILS: Online playback automatically loads the selected original subtitle source, preferring automatic English. Source controls show a single original-source summary rather than a platform translation-language list, with retry after a load failure. OnlineTranslationTools provides enable/pause/resume, target language, current-position status and completed/total counts, cache guidance, an inline alert and AI settings access. Target language is disabled while connecting or running; settings pauses media. Before starting, help states that subtitles go to the configured AI service and may incur API charges. Existing translations remain watchable when paused. Online cues and translations share the existing list and SubtitleOverlay appearance. At <=650px content height, the online sidebar scrolls as a whole, its direct children do not shrink, its heading/close control stays sticky against the theme surface, and its 240px subtitle list scrolls internally. Transport stays outside this scroll region. This is an incumbent Warm Paper/MiSans/Phosphor refinement with no new assets or main design workflow.

ONLINE FINISH: Independent proxy visual/code review returned SHIP with no material findings across exactly seven PNG captures in .impeccable/review/desktop-online/: online-light, online-dark, online-narrow-light, online-narrow-dark, online-narrow-list-light, online-narrow-list-dark and online-error-light.
