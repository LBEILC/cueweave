# CueWeave 开发路线图

路线图只定义交付顺序与阶段完成条件；稳定产品要求以[产品需求](PRODUCT_SPEC.md)为准。

## 当前进度

- Phase 0、1、1.5、2、3 已完成核心实现并有自动化测试。
- Phase 4 已完成当前位置优先、前方窗口预取、并发限制、任务去重、进行中请求主动取消、YouTube 单页导航会话隔离、IndexedDB 持久缓存、稳定缓存键、LRU，以及当前视频/全部缓存管理；仍需 Service Worker 恢复专项验收。
- Phase 5 已完成 Popup、独立 Options、字幕工作台、原文/中文/双语模式、双语顺序、字号、位置、字幕文字底板、高置信度转录修正、按视频术语记忆和完整视频翻译进度；仍需颜色/字重以及影院、全屏、Shorts 的完整验收。
- Phase 6 已完成 SRT / WebVTT 序列化、导出校验和原始转录/修复原文/中文/双语导出入口；仍需常见播放器兼容性回读验收。
- Phase 7 尚未开始。

## Phase 0：项目基础

- 建立 WXT + TypeScript Manifest V3 工程。
- 配置开发、构建、类型检查、测试和打包命令。
- 补做上游固定提交的本地审计。
- 建立第三方版权声明。
- 生成可被 Chromium “加载已解压的扩展程序”接受的最小产物。

完成条件：干净安装可以生成扩展产物；浏览器能加载；静态检查与空测试套件通过。

## Phase 1：字幕管线

- 建立领域数据结构和版本化消息协议。
- 实现字幕获取适配层。
- 实现标准化、噪声识别和滚动去重。
- 实现本地规则断句。
- 加入固定字幕样本与边界测试。

完成条件：不接入模型也能从样本稳定生成带时间轴的本地显示字幕；真实页面能显示降级原文字幕。

## Phase 1.5：词级时间与显示分层

- 保留 YouTube JSON3 的词级时间偏移。
- 将完整语义句与屏幕显示字幕拆成独立领域结构。
- 本地降级识别 cue 内部标点，并在从句或短语附近限制显示长度。
- 建立连续词元窗口、覆盖校验和中文显示长度约束。

完成条件：真实长句不会在冠词、助词或未完成短语后被硬截断；模型输出可以映射回程序持有的词级时间；不合规输出可靠回退原文。

## Phase 2：OpenAI 兼容 Provider

- 建立 Provider 契约和统一错误分类。
- 支持 Chat Completions、Responses 与自动检测。
- 实现运行时 origin 权限。
- 建立 Provider 设置页和连接测试。
- 使用本地模拟服务覆盖成功与故障路径。

完成条件：无需真实 API Key 即可跑完 Provider 集成测试；密钥不会离开 background 上下文。

## Phase 3：AI 语义重组

- 构建上下文窗口与提示词版本。
- 实现 JSON Schema 和 cue 完整性校验。
- 实现一次严格重试与本地降级。
- 将合法分段映射回程序时间轴。

完成条件：遗漏、重复、乱序、未知 ID 和非法 JSON 均被测试捕获；所有失败都产生可显示的降级字幕。

## Phase 4：调度与缓存

- 实现播放位置优先队列、并发限制和取消。
- seek 后重新排优先级。
- 实现 IndexedDB 缓存、缓存键和 LRU。
- 处理 Service Worker 回收与视频切换。

完成条件：seek 与快速换片不会串结果；相同有效输入命中缓存；配置变化可靠失效。

## Phase 5：产品界面

- 完成 Popup 和 Options 信息架构。
- 完成原文、中文和双语模式。
- 完成字幕样式与播放器内状态。
- 适配影院、全屏和 Shorts。

完成条件：常用操作无需进入设置页；所有错误给出发生位置和恢复动作；键盘与缩放可用。

## Phase 6：字幕导出

- 实现 SRT 与 WebVTT 序列化。
- 实现时间、编号、内容和文件名校验。
- 加入中文、双语和修复原文导出入口。

完成条件：固定样本通过解析回读测试，并可被常见播放器读取。

## Phase 7：发布准备

- 完成端到端与手工验收矩阵。
- 审核权限、CSP、隐私说明和第三方许可证。
- 生成可安装 ZIP 和可复现构建记录。
- 整理已知限制与发布说明。

完成条件：CI 从干净检出生成通过验收的安装包，仓库中不含密钥、字幕缓存或用户数据。
