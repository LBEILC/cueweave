# D1：字幕项目闭环

2026-09-05：本机已完成字幕项目的创建、导入、编辑、保存、重开、撤销重做、媒体重新定位和导出回读验收。翻译与 ASR 分别由 D2、D3 接入。

## 使用流程

1. 打开本地视频，或将链接视频下载后打开，点击顶栏「创建项目」，选择新的 `项目名.cueweave` 目录。
2. 在字幕侧栏「导入字幕」，选择 UTF-8（可带 BOM）的 SRT 或 WebVTT。无效时间、空内容、超过视频范围或无法解码的文件会被拒绝；样式、位置、VTT 元数据的简化会显示说明。
3. 点击字幕旁的铅笔，修改文本或开始、结束时间，点击「保存修改」。事务提交后显示已保存；无需再执行整个项目的保存操作。未保存的表单保留在窗口内，切换操作受限，关闭窗口时提示返回编辑或放弃草稿。
4. 使用撤销、重做；导入另一份字幕会建立独立字幕轨，原轨、已保存修改和撤销历史仍保留，可从字幕轨下拉框返回。
5. 在「导出字幕」中选择原始字幕或编辑后字幕，再选择 SRT / WebVTT。导出不读取正在修改的表单。

下次启动自动恢复最近项目，或使用「打开项目」选择 `.cueweave` 目录。视频移动或内容改变时，字幕仍可编辑和导出；重新定位只接受 SHA-256 与原视频一致的文件。

## 存储与一致性

- 项目目录包含 SQLite 数据库及运行时可能存在的 WAL/SHM 文件。备份和移动时应关闭项目并复制整个目录，不只复制正在使用的数据库主文件。原始字幕文件的完整字节以 BLOB 保存在项目内，规范化原始 cue、活动编辑结果及每轨的历史独立保存。
- 项目包含 UUID、schema 1、修订号、活动轨、段级时间精度、未指定语言 `und`、视频原路径与相对路径、SHA-256、大小、探测信息和播放位置。原视频默认引用，未复制进项目。
- SQLite 由 utility process 串行处理，开启 WAL 和 `synchronous=FULL`。编辑、导入和轨道切换在事务内检查 `projectId` 与 `baseRevision`；过期命令不会覆盖已保存内容。失败事务回滚，不显示草稿已保存。
- 播放位置定期、暂停时及正常关闭时保存。正常重开验证媒体内容；后台服务异常退出后，下一次项目操作重新连接服务并从数据库继续。已有编辑和每轨撤销历史不依赖 renderer 内存。
- 导入任务与结果在同一事务中完成。导出任务记录运行状态、输入修订和目标检查点；重开时尚未完成的运行任务标记为 interrupted，不静默重跑。导出先写同目录唯一临时文件，刷新磁盘、回读全部内容和时间，再重命名到目标。失败不会把不完整临时文件标为成品。
- 首次项目格式为 schema 1。更高或未知版本拒绝写入；当前没有已发布旧格式的迁移路径。将来增加迁移时必须先通过 SQLite 一致备份 API 备份，不能用普通文件复制代替在线数据库备份。
- Renderer 只有固定的项目动作与 DTO；路径来自宿主文件对话框或最近项目记录。窗口、主框架、参数结构和项目授权分别检查。导出不得覆盖项目目录内的文件，内部文件系统异常不会回传路径。

## 已验证范围

```powershell
npm run test:desktop:project
```

在需要 GPU 沙箱兼容开关的本机环境中，按 D0 文档设置 `CUEWEAVE_TEST_DISABLE_GPU_SANDBOX=1`。所有媒体验收保持静音，使用隔离用户目录。

- `project-storage-check.mjs` 使用实际 Electron ABI 的 SQLite：精确原文件保留、毫秒时间与自然重叠、编辑、撤销重做、跨轨恢复、关闭重开、过期与并发写入拒绝、媒体内容重新定位、未来 schema 拒绝、导出回读与中断任务标记。
- 磁盘不足测试在事务已经修改 cue、尚未提交时注入 `SQLITE_FULL`，再重开确认文本与修订号均未变化；这是故障注入，不是耗尽用户磁盘。
- `project-acceptance.mjs` 使用真实隐藏窗口完成创建、导入、文本及时间编辑、撤销重做、导出、未保存关闭保护、重启恢复位置、杀死后台服务后继续操作、缺失媒体及重新定位。对 1280×782 内容区和 640×480 内容区检查布局，覆盖浅深色。
- 同一脚本使用本地媒体模拟长清晰度标签，测量完整文字宽度、箭头右侧间距和所有播放控件边界，并实际点击进入、退出全屏。模拟链接不访问外部站点。

报告和截图输出到被忽略的 `.impeccable/review/desktop-project/`。样本字幕、视频和项目都是验收数据，不作为产品默认内容。

## 当前边界

持久项目使用本地或下载后的视频。在线播放和站点字幕预览保持可用，但流式链接尚不直接建立可长期恢复的编辑项目。导入上限为 10 MB / 50000 条字幕；字幕同步使用毫秒与段级 cue，不推测词级对齐。首次创建和重开需校验完整视频哈希，大文件会增加等待时间。长片性能、分页读取、付费任务恢复、翻译覆盖门槛和已发布格式迁移不由这轮短样本验收证明。

## 窗口与图标修复

默认原生窗口调整为 1280×820，按主显示器可用桌面限制尺寸，并记住正常窗口大小。最小尺寸仍为 640×480。全屏权限仅允许应用自己的主框架；其他权限仍保持关闭。原生下拉框统一自绘箭头与 12px 右间距，长清晰度标签使用完整所需宽度，900px 及以下播放控件分两行。

开发窗口和打包窗口共用现有多尺寸 `icon.ico`，Windows AppUserModelID 与安装包一致；打包时把窗口图标复制到固定资源路径。可执行文件、安装器和快捷方式继续使用同一品牌图标。
