# 桌面设置

2026-09-05：桌面端提供外观、字幕显示与单个 AI 服务配置。翻译流程和任务边界见 [D2 实施与验收](DESKTOP_D2.md)，语音识别仍属于 D3。

## 使用

从顶栏「设置」进入。进入时暂停视频，播放器和字幕编辑状态保持挂载；返回工作台继续操作。

- 外观支持浅色、深色与跟随系统。保存成功后通过 Electron `nativeTheme` 应用到整窗和原生控件，重启恢复；跟随系统响应系统外观变化。
- 字幕显示支持原文／译文／双语、顺序、字号、双语原文相对大小、垂直位置、底板和阴影。设置内实时预览，保存后应用到播放器；可恢复默认，重启保持，不改变导出文件。未保存样式和 AI 配置一起参与离开保护。
- AI 服务支持兼容 Chat Completions / Responses 的接口。填写基础服务地址、模型名称和 API Key，选择自动或明确协议，再保存。生产初始配置为空，不预设服务商、模型或密钥。
- 自动协议先尝试 Chat Completions，仅在模型不存在或响应格式无效时尝试 Responses。远程服务使用 HTTPS，本机回环服务可使用 HTTP；不接受 URL 内的用户名、密码、查询参数或片段。
- 已保存密钥不回显。更换模型保留密钥，更改基础服务地址清除旧密钥；移除密钥需保存才生效，保存前可撤销移除。提交密钥后立即清空输入，保存失败时提示重新输入。
- 测试连接只使用已保存配置，发送一条固定短请求，不读取视频或字幕。会调用服务商的真实模型接口，可能产生费用；可取消，20 秒超时，失败显示可操作原因。通过表示收到有效模型响应，不保证整片字幕翻译质量或额度。
- AI 表单有未保存修改时，返回显示确认并把焦点移到「继续编辑」；关闭窗口也有保留草稿提示。窄窗表单独立滚动，保存和连接反馈固定可见。

## 保存与边界

全局配置写入应用用户目录的 `settings.json`，与 `.cueweave` 项目分离，也不自动沿用浏览器扩展配置。主进程通过 `safeStorage` 加密密钥，renderer 只能取得 `missing / saved / session / unavailable` 状态；已保存密钥不通过桥接返回。加密不可用（包括 Linux `basic_text` 后端）时只保留会话内密钥，不明文落盘；当前发行和实机验收平台为 Windows x64。

配置变更串行写入同目录唯一临时文件，刷新后原子替换。写入失败不更新内存状态或显示已保存；损坏或未知格式的原配置保留，不静默覆盖。密钥无法解锁时允许重新输入或移除。

固定 IPC 检查窗口、主框架、页面 URL 和命令字段。测试由宿主执行，使用共享 Provider 实现，拒绝重定向，响应上限 1 MiB，服务端响应正文与内部网络异常不回传用户界面。测试期间拒绝重叠测试和配置保存，退出时取消请求。

## 验证

```bash
npm run test:desktop:settings
```

真实 Electron 验收使用隔离用户目录与本机模拟服务，覆盖浅深与系统主题、加密保存及重启、两种接口、认证失败、无效响应、取消、重定向隔离、密钥移除、鼠标/键盘返回及窗口关闭草稿保护。截图覆盖 1280×782 和 640×480 内容区，含两种主题、表单滚动与错误反馈；报告保存在忽略目录 `.impeccable/review/desktop-settings/`。所有测试静音，不使用真实用户密钥或付费服务。

单元测试另覆盖 IPC 授权、并发拒绝、响应大小上限、写入失败、损坏配置、加密不可用和无法解锁密钥。加密单元测试使用替身；Windows 实机重启验收使用真实系统加密。

快速迭代默认只构建与验收，不生成安装包。CI 的 Windows 安装器构建、产物检查与安装卸载仅在手动运行并选择 `build_installer` 时执行。
