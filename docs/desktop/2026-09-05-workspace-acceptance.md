# 桌面工作台重构验收 · 2026-09-05

本次在 D0 媒体能力之上重构桌面交互，不改变 D1–D3 的字幕编辑、项目持久化、翻译和 ASR 交付边界。用户确认 A 布局（视频 + 可收起字幕侧栏），并批准由 `design-from-constraints` 探索、`impeccable` 实施。设计依据见 [Desktop workspace](../../DESIGN.md#desktop-workspace)。

## 交付范围

- 播放区按窗口剩余空间缩放，固定应用操作、媒体标题、播放控制和任务状态；整窗不滚动。
- 字幕面板独立滚动，支持来源选择、搜索、当前句标记、点击定位及偏移设置；来源设置可折叠。小窗口面板覆盖画面右侧，播放控制保持可见。
- 关于与导入使用独立对话框，关闭时恢复焦点；当前媒体元素、暂停状态、位置和字幕不会因打开对话框而重置。
- 导入、关于、字幕面板与对话框拆分为独立组件，媒体格式化与解析从应用编排组件移出。
- 自动媒体测试静音启动，测试 WebContents 也禁用音频输出；正常交互播放与系统音量保持原有行为。
