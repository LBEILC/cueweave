# 固定初稿的复核范围对照

2026-09-05：小范围审校未显示足够收益，未接入生产。交付的是实验中发现的“已有中文被退回整段英文原文”保护，以及可复用的固定初稿对照工具。未生成新的综合质量分数。

## 方法

从旧质量基线 `three-modes-quality-final` 提取五个复核前的完整窗口，共 36 条固定草稿，来自同一组三个公开视频。三个窗口包含此前发现的价格属性、词语语境和嵌套动作问题，另两个窗口包含人工初查未发现实义错误的 13 条对照字幕。所有候选使用相同原文、初稿、模型 `gemini-3.5-flash-lite`、复核提示词与输出 Schema；不重新初译。

- 不复核：保留输入草稿，无模型调用。
- 整窗：每个固定窗口一次复核。
- 局部：按顺序每三条分组，不拆条、不改 ID，邻近两条原文仅作只读上下文，不附带其草稿。

每种复核范围各重复两次，交替执行顺序，总共 36 次真实调用。失败组保留草稿，不排除失败结果。此次模型结果仅通过原文引用和 ID 结构校验，没有走完整字幕规范化与专名等生产校验；以下称“候选结果”，不冒充已上线表现。

## 结果

| 指标                            | 整窗复核 | 三条局部复核 |
| ------------------------------- | -------: | -----------: |
| 固定窗口 × 重复                 |    5 × 2 |        5 × 2 |
| 模型调用                        |       10 |           26 |
| 超时调用                        |        1 |            3 |
| 无效原文引用                    |        0 |            2 |
| 每个窗口串行复核耗时中位数      |  1.52 秒 |      3.92 秒 |
| 三个已知错误 × 两次重复中的修复 |      2/6 |          3/6 |
| 对照字幕退回英文原文            |        0 |            1 |

耗时含失败和超时，是离线实验值，不是播放器 SLA。局部比整窗多修复一次词语语境问题，却用了 2.6 倍调用，并出现额外退化；样本过少，不能推断稳定的修复率或精确速度倍数。

### 预先选定的问题

| 原文要点与初稿问题                                    | 整窗两次           | 局部两次                   |
| ----------------------------------------------------- | ------------------ | -------------------------- |
| `more expensive` 被译成“更强大”                       | 2/2 修复为价格含义 | 2/2 修复为价格含义         |
| 讲解频率词时 `normally` 被译成“正常”                  | 0/2 修复           | 1/2 改为保留被讲解的英文词 |
| `teaching the body to recognize an attack` 漏掉“识别” | 0/2 修复           | 0/2 修复                   |

这些是主代理对预先选定问题的定点核对，不是独立盲评，也不是整段准确率。价格窗口内另有两条草稿的含义错位，两种范围也都尝试修正；未把这些额外发现混入上述三个预定问题的分母。

### 正确内容被改坏

局部第二次运行将 `So, Neil, what is your favourite food?` 对应的“尼尔你最喜欢的食物是什么”改成了原封不动的英文。该候选提供的原文引用真实存在，因此原来的引用校验无法阻止它。

此外，有候选把已正确翻译的“免疫反应”换成英文 `immune response`，或仅修改空格、标点。并非所有带引用的改动都必要或有益，不能将“引用有效”视为语义正确。此轮没有穷尽所有潜在退化，也未加入新的 holdout 视频：开发集对照已不足以支持推广局部方案，先不消耗未参与调试的材料来调整它。

## 本轮生产改动

共享词元路径的复核增加保守保护：当已有译文包含中文，新译文完全不含中文、与含至少四个英文词的原文一致（忽略大小写、空白和标点），拒绝该组修订并保留初稿。短名称、仍含中文的双语解释、原本就是英文的草稿，以及上下文明示原样保留的完整术语不触发此保护。

该规则只防止整段退回原文，不能识别混合译文中的局部漏译或错误英语替换，也不证明原草稿正确。对于未登记为原样保留术语的长名称，它可能保守地留下已有中文名称；可通过术语配置表达需要原样保留的名称。

使用本次 30 组原先通过引用校验的录制响应回放，新增规则仅拦截上述退回英文的组。另有单元与核心流程测试验证回退、大小写/标点变化和名称例外。没有增加模型调用、改变窗口或默认档位。缓存策略版本更新为 `playback-policy-v5`，词元流程版本为 `first-pass-v6`。不据此声明桌面固定 cue 路径使用该复核。
