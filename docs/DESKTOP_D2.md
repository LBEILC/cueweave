# D2：字幕翻译与显示设置

2026-09-05：桌面端接入保留 cue 时间的翻译、检查点恢复、译文校对与译文／双语导出。字幕显示设置位于既有设置页。语音识别仍属于 D3，本阶段使用已经导入项目的字幕；持久项目仍基于本地或下载后的视频。

固定 cue 的分窗、提示词、输出检查与格式恢复已收敛至共享核心 `provider/cueTranslation`，桌面适配器仅保留网络限制和错误文案。在线跟播也复用该入口，见[在线边看边译](DESKTOP_ONLINE_TRANSLATION.md)。这不代表 C2 统一任务契约或桌面三档策略已完成。

## 使用流程

1. 在设置中保存 AI 服务地址、模型、接口协议和 API Key。字幕翻译使用这份桌面配置，不继承扩展配置。
2. 打开字幕项目，在侧栏展开「翻译字幕」，核对显示的服务、模型和目标语言，点击「翻译当前字幕」。字幕和有限的邻近上下文会发送到所配置服务，可能产生 API 费用；不发送视频、音频、媒体路径或项目文件。
3. 进度按已经提交的字幕条数显示。参数区在开始后折叠，已完成译文出现在对应原文下方；字幕搜索同时匹配两种文本，点击仍按原时间定位。
4. 点击铅笔，在「原文与时间」和「译文」之间选择校对内容。译文有独立撤销／重做历史；人工编辑和撤销后的文本都不会被迟到的机器结果覆盖。未保存草稿仍有切换与关闭保护。
5. 取消保留已提交结果，失败或中断后可点击「继续剩余字幕」。相同输入、目标语言、服务配置与管线身份复用已有结果；更换模型或服务后，使用「翻译当前字幕」建立新配置对应的任务。
6. 在「导出字幕」中选择译文或双语，再选择 SRT / WebVTT。缺少译文时默认不能完整导出；可主动勾选「仅导出已完成部分」，默认文件名带「部分」。双语文件按原文、译文排列。原始和编辑后原文仍可独立导出。

修改原文或时间会使对应输入身份改变，旧翻译不再显示为当前结果。旧任务及已保存译文保留在数据库中；恢复原输入或切回原字幕轨时可以复用匹配结果。当前没有用于任意浏览所有历史模型版本的独立界面。

## 字幕显示

设置页的「字幕显示」提供原文／译文／双语、双语顺序、字幕大小、双语原文相对大小、距底部位置、底板开关与不透明度、阴影开关与强度，以及恢复默认。预览和播放器共用字幕组件；预览文字明确属于样式示例，不作为项目字幕或翻译输入。

调整时更新预览，保存后应用到播放器并在重启后恢复。未保存的字幕样式与 AI 配置分别保留草稿，并共同参与离开确认。没有译文时回退显示原文。显示偏好独立于项目，只影响观看，不向 SRT / WebVTT 写入样式或更改字幕时间。

## 存储与任务边界

- 项目升级为 schema 2。打开 schema 1 项目时，先通过 SQLite 备份 API 写入项目目录内唯一的 `project-schema-1-*.sqlite` 一致备份，再在事务中创建翻译表并更新版本。未知更高版本拒绝写入。原字幕、媒体引用和 D1 编辑历史保持保留。
- 项目服务仍是数据库唯一写入者。翻译任务运行于 utility process；每个窗口的网络调用在数据库队列之外执行，提交结果时才进入串行事务，不把一次整片翻译挂在长 IPC 上。
- 桌面主进程只向已授权项目注入保存的 Provider 配置和按需解锁的密钥。密钥不写入项目、检查点或错误信息，不回传 renderer。翻译配置身份仅包含服务地址、模型、协议、目标语言、源 cue 内容与时间的哈希，以及管线版本。
- 每个窗口最多 20 条 cue，通常不超过 6000 个源字符；单个长 cue 保持完整，不制造新的时间边界。上下文只取前后各两条并限制文本长度。模型按原 ID 和原顺序逐条返回译文；重复、缺失、未知 ID、额外时间字段、无效 JSON 和空内容被拒绝，格式失败最多补做一次严格重试。
- 复用共享 Provider 传输，支持 Chat Completions、Responses 与自动协议。宿主请求拒绝重定向和跨 origin 凭据传递，限制响应为 1 MiB，单窗口整体等待上限为 90 秒；共享传输还有自身的请求超时和有界瞬时重试。错误不显示远端原始响应正文。
- 任务持久化状态为 running、cancelled、interrupted、failed、completed，逐窗口提交检查点。项目服务同时只执行一个整片字幕翻译任务；开始其他整片任务前需要完成或取消当前任务。在线跟播是独立的、有界桌面会话。
- 开始／编辑仍检查项目修订。机器提交额外核对任务执行代次、当前源字幕身份和人工修改标记；机器检查点不推进人工编辑修订号。进度读取是独立只读入口，以约 800 ms 间隔刷新，避免占用编辑操作入口。
- 正常退出中止活动请求并保留检查点。后台进程异常退出时，下一次读取恢复数据库中的任务为 interrupted；重新打开项目不会自动恢复模型调用。若请求已在远端执行但响应尚未提交，主动继续可能再次调用该窗口，不能保证远端恰好执行一次。
- 导出从数据库取得一致的当前输入与译文快照，应用人工修订，检查覆盖范围；沿用同目录临时文件、刷新、完整回读、原子替换流程。输出中的标签字符转义，原时间及自然重叠保持不变。

## 验证与当前边界

```powershell
npm run test:desktop:translation
```

GUI 验收需要冒烟测试生成的 `.fixtures/desktop/D0 中文 sample.mp4`；CI 在冒烟后运行。测试使用隔离用户目录、本机模拟模型服务和静音 Electron 窗口，不使用真实用户密钥，不发起付费模型调用。

- 纯逻辑测试覆盖逐 cue 输出、完整性拒绝、窗口划分、IPC 命令校验、显示字段校验、响应上限及格式重试。
- 原生 SQLite 验收覆盖 D1 迁移与一致备份、持久检查点、中断恢复、过期代次、人工修改和撤销保护、磁盘满事务回滚、缓存身份、源修改失效、译文／双语导出及回读。
- 真实桌面验收覆盖样式预览和保存、翻译中编辑、取消续做、部分导出、完整导出、重开后结果保留、杀死后台进程后的继续、两种接口、无效输出、认证失败和重定向隔离。截图及报告位于忽略目录 `.impeccable/review/desktop-translation/`。

首版质量目标仍是英语字幕到简体中文。界面提供简体中文、繁体中文、英语、日语、韩语目标；实际语言质量取决于配置的模型，模拟接口验收不证明真实模型翻译质量。词级重组只在未来获得并验证可信词对齐后接入；当前不会估算词时间。超长视频性能、字幕分页与批量任务仍按后续阶段验收。

快速迭代不生成安装包，只有用户明确要求时才打包。本次功能验收不代替新安装器的安装、卸载与签名验证。
