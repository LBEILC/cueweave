# 桌面在线边看边译

2026-09-05：在线播放不再要求先下载视频或创建项目才能翻译已有在线字幕。

## 观看流程

1. 在设置中保存 AI 服务、模型和 API Key。
2. 读取支持的视频链接并选择「在线播放」。客户端自动读取一条原文字幕；英文视频优先英文自动字幕，缺失时回退到英文人工字幕。平台自动翻译的其他语言轨道不作为原文来源，也不列出全部轨道。
3. 在字幕侧栏点击「开启翻译」。客户端从当前播放位置开始翻译并预取后续字幕，播放器和侧栏同步显示原译文。字幕样式沿用设置页的原文／译文／双语、顺序、字号和底板偏好；译文尚未就绪时显示原文。
4. 拖动播放进度后，新位置优先。暂停翻译保留已有结果，继续时复用缓存。切换目标语言先隐藏旧语言译文。切换视频不自动发起新的模型调用。

开启翻译会向已配置的模型服务发送字幕文本与有限邻近上下文，可能产生 API 费用。不会发送视频、音频或站点登录凭据。播放暂停期间可以完成当前位置附近的有限预取；「暂停翻译」才会取消模型请求。更改 AI 配置后，在侧栏暂停并继续翻译以使用新配置。

## 实现边界

- 跟播调度位于桌面主进程，网络和缓存均异步执行；一个在线会话只保留一个活动翻译窗口。模型提示词、输出 Schema、校验与一次格式修复调用共享核心 `provider/cueTranslation`。桌面不复制提示词。
- 当前窗口至多 8 条 cue、通常不超过 4000 个源字符或 30 秒；单个长 cue 保持完整。向后预取限于当前位置之后 90 秒。跳转离开工作区间时取消过时请求；取消后即使远端完成响应，也不能更新当前会话。
- 在线自动字幕使用核心 `normalizeRollingCues` 移除有时间重叠和逐行文本证据的滚动重复；不同时间的重复台词保留。不估算词级时间，不宣称已接入扩展的词元语义重组或三档策略。
- 原文由主进程通过已授权轨道取得并解析，再发给 renderer。翻译 IPC 只接受已发出的源 ID、动作、播放位置和目标语言，不接受 renderer 传入的路径、凭据或字幕内容。载入另一条字幕后旧源失效。
- 模型访问沿用主进程保存的配置，限制同 origin、拒绝重定向、响应至多 1 MiB，单窗口上限 90 秒。错误文本经过本地归类；模型出错后停止调度，需要主动继续，不因轮询反复请求。
- 缓存写入用户数据目录的 `online-translation-cache`，以输入内容及时间、目标语言、Provider 地址／模型／协议、管线版本区分，键中不含密钥。每窗口通过临时文件和原子替换提交；读取限制 8 MiB，最多保留最近写入的 20 份缓存。缓存损坏视为未命中；磁盘写入失败停止翻译并报告错误，已显示结果仍留在本次会话中。
- 重启或重新打开链接会重新取得原文，不会自动调用模型；主动开启后可复用等价缓存。缓存只是观看结果，不替代持久项目和人工校对历史。整片任务、人工编辑与 SRT / WebVTT 导出仍通过 [D2 字幕项目](DESKTOP_D2.md) 进行。
- 无原文字幕的视频、普通视频直链附带字幕的自动发现和在线音频识别未接入；没有字幕时仍需手动加载字幕文件观看或等待 D3 ASR。已有在线字幕翻译不依赖 ASR。

## 验证

```powershell
npm run test:desktop:online
```

需要先由桌面冒烟生成媒体 fixture。验收使用独立用户目录、隐藏静音 Electron 窗口、本机模拟模型接口，以及仅替换媒体站点上游的测试适配器；真实 IPC、设置、安全密钥、跟播调度、核心请求、缓存和 renderer 全部参与执行。覆盖自动选轨、无配置提示、双语播放、清晰度切换、取消续做、跨源隔离、两种接口、认证失败和缓存重启。单元测试另覆盖远距离跳转优先、取消后迟到结果、自动翻译轨道过滤及滚动字幕去重。

该验收验证功能和请求边界，不证明真实模型翻译质量或特定模型的实时延迟。真实 YouTube 选轨和字幕播放单独通过 `CUEWEAVE_LINK_ONLY=youtube` 的链接验收复验。快速迭代不生成安装包。
